## Что уже сделано

### Оформление (готово)
- Направление — «наставник рядом». На странице два голоса: набранный
  текст курса и короткие реплики наставника от руки на левом поле.
- Шрифты: теория Literata 17.5px, интерфейс Onest, реплики Caveat,
  код JetBrains Mono. Заголовки — Literata, интерфейсные подписи — Onest.
- Реплики лежат в `lessons.js` в поле `say` — по одной на каждый урок
  и на каждый модуль. Компонент `.aside`; на широком экране уходит на
  поле (порог 1200px для урока, 1400px для главной), на узком
  становится блоком с чертой слева.
- Правило радиусов: контейнеры 13px, контролы 7px, других нет.
- Правило цвета: один акцент — фиолетовая ручка #6B4FC9. Маркер #FFE59E
  ставится ровно в одном месте на урок — на врезку `callout jobs` про
  собеседования. Зелёный/красный/янтарный только для состояний.
- Шаблонной мишуры нет намеренно: ни капслока с разрядкой в ярлыках,
  ни средних точек в мета-строках, ни клетчатого фона под обложкой.
- `app.js`: страница урока — один лонгрид (шапка, план занятия, якорная
  навигация, теория, задача, тренажёр, самопроверка, ссылки, заметки).
  Главная: обложка, модули карточками, асимметричный блок про рынок.
  Появление блоков при скролле сделано проверкой координат, а не
  IntersectionObserver (наблюдатель молчит при переходе по якорю).

### Перенос прогресса (готово)
- Прогресс лежит в localStorage под ключом `da.state.v1`. Ключ не зависит
  от имени и расположения файла, поэтому новая сборка курса, открытая
  в том же браузере, подхватывает занятия сама.
- `Store` при отсутствии своего ключа ищет любой прежний `da.state.*`
  и забирает прогресс оттуда — смена версии ключа не обнулит занятия.
- `Store.merge` вместо `replace`: пройденное объединяется, время и попытки
  берутся большие, код и заметки из файла кладутся только туда, где пусто.
  Перенос ничего не стирает.
- Файл прогресса принимается перетаскиванием в любое место страницы
  (`acceptDroppedProgress`), а на пустом курсе под обложкой появляется
  строка с предложением перенести.
- Чего сделать нельзя: автоматически перетащить прогресс между разными
  origin (файл с диска против localhost, другой браузер, другой компьютер).
  Это граница безопасности браузера, обходится только файлом.

признаков `feat`: одна строка на пользователя, поведение первой недели

`инструменты/mlprelude.sh` с решением урока и запускает.
