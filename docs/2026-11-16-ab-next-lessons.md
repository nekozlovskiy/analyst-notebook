Числа SRM пересчитаны через chi2=(a-b)^2/(a+b) и erfc(sqrt(chi2/2));
для 48 213/52 104 это формальная модель независимых наблюдений,
по сессиям она не заменяет проверку исходного назначения пользователей.
Для 12 независимых проверок 1−0,95^12≈0,45964;
это иллюстрация, не точная вероятность для зависимых метрик дашборда.
