# Песочницы «покрути»: первая — ЦПТ в уроке 3.1

Дата: 2026-09-28. Этап 3 плана улучшений («Наглядность»), подпроект после схем в теории.

## Зачем

Ученик идёт с нуля по ссылке, часто с телефона. Самые абстрактные темы (ЦПТ, ROC-порог, MDE ↔ размер выборки, рамка окна `ROWS BETWEEN`, шаг градиентного спуска) объясняются словами и статичной схемой. Песочница даёт самому подвигать параметр и увидеть то, что текст утверждает: например, что разброс средних падает как √n.

Критерий успеха: двигая ползунок, ученик видит, как меняется форма и разброс, а числа в песочнице совпадают с текстом урока.

## Решения владельца курса

- Порядок: сначала одна песочница — ЦПТ в уроке 3.1 (`m3l2`), отладить механизм, выложить; остальные — тем же механизмом, по одной.
- Место (вариант A из макетов): схема сама становится песочницей, отдельного блока нет.
- Данные (подход 1): всё считается заранее в `инструменты/figs.py`, JS только перерисовывает. Ползунок прыгает по фиксированному набору положений.

## Что видит ученик

- На месте трёхпанельной схемы `clt-means` — одна гистограмма «средние 2000 выборок, руб.»: ось 0–11 000, корзины по 250 руб., вертикаль «среднее 3457».
- Под ней ползунок n по положениям 1, 2, 3, 5, 10, 20, 30, 50, 100, 200 с засечками 1 · 5 · 30 · 200. Исходное положение — n = 30.
- Строка чисел: «n = 30 · разброс 323 · по формуле σ/√n 316». При n = 5 — 779 и 773, как в тексте урока.
- Гистограмма — ручкой (`f-pen`); серым контуром (`f-raw`) под ней всегда лежат сами чеки (n = 1).
- Реплика почерком внутри схемы: «двигайте n — колокол сужается как √n».
- Перерисовка мгновенная, без анимации (в курсе одна анимация — `ink-in`).
- Ползунок — стандартный `<input type="range">`: палец, мышь, стрелки. `aria-valuetext` — «n = 30, разброс 323».
- Подпись рисунка начинается с «Двигайте ползунок: …».
- Если JS не отработал или данных песочницы нет — остаётся нынешняя статичная схема «1 / 5 / 30».

## Устройство

### Данные — `инструменты/figs.py`

- `clt_sandbox()` считает для каждого n из набора средние 2000 выборок с возвращением из оплаченных чеков тем же способом, что задача урока: `random.Random(42)` заново для каждого n, `choice` n раз, строки в порядке `order_id`.
- Для каждого n: счётчики корзин по 250 руб. на оси 0–11 000, разброс по опыту (выборочное стандартное отклонение), разброс по формуле σ/√n, где σ — стандартное отклонение совокупности.
- Общие поля: среднее совокупности, шаг и граница оси, набор n, исходное положение.
- В блок `FIGS:BEGIN/END` файла `content-m3.js` пишется строка `window.SANDBOX["clt-means"] = {...}` (JSON, порядка 5–8 КБ). SVG в `window.FIGS["clt-means"]` остаётся как запасной вариант.

### Код — модуль `Sandbox` в отдельном `sandbox.js`

Функции песочниц — в своём файле `sandbox.js` (подключается перед `app.js`, встраивается `build.py`, лежит в кеше сервис-воркера): `app.js` в node не загружается, а чистые функции рисования проверяет `checkfigs.js`. `app.js` только вызывает `Sandbox.mount`.


- `Sandbox.draw["clt-means"](data, i)` — чистая функция: данные и номер положения → строка SVG. Классы те же, что у схем (`f-pen`, `f-raw`, `f-sub`, `f-note`…), поэтому тёмная тема работает сама. Размеры в духе схем: `viewBox` шириной 340.
- `Sandbox.mount(root)` вызывается сразу после `Figs.mount`. Для каждой `figure[data-fig]`, у которой есть и `window.SANDBOX[id]`, и `Sandbox.draw[id]`, заменяет статичную SVG живой, добавляет ползунок и строку чисел. Повторный вызов ничего не удваивает.
- `Sandbox.label[id](data, i)` — текст строки чисел и `aria-valuetext`; тоже чистая функция.

### Стили — `styles.css`

Блок `.sbx`: ползунок цвета ручки (`accent-color: var(--pen)`), строка чисел, засечки, отступы. Ширина как у схем: на телефоне по ширине колонки, на компьютере по центру не шире 520 px.

### Следующие песочницы

Каждая добавляет функцию данных в `figs.py`, свою `Sandbox.draw[id]` и `Sandbox.label[id]`. Механизм монтирования, стили и проверки общие.

## Проверка

1. `figs.py m3 --check` дополнительно сверяет данные песочницы: n = 5 → разброс 778,80, n = 30 → 323,06; сумма счётчиков каждого n равна 2000.
2. `checkfigs.js` загружает `app.js` и данные в node и вызывает `Sandbox.draw["clt-means"]` и `Sandbox.label["clt-means"]` для всех положений: результат — непустой `<svg …>` без `NaN` и `undefined`, в строке чисел — разброс из данных. Входит в `ci.sh`.
3. `checkfigs.js` проверяет соответствие: у каждой записи `SANDBOX` есть функция рисования и схема в теории урока, и наоборот.
4. Глазами в браузере на 390 px: все положения ползунка, тёмная тема, управление стрелками, запасной вариант без данных песочницы.
