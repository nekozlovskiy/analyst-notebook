# Вводный урок 0.2 «Python с нуля»

Дата: 2026-09-19. Ветка: `intro-python` (от `main`).

## Зачем

Урок 2.1 с первых строк считает известными `print`, переменные, списки,
вызов метода через точку, аргументы по имени (`how="left"`) и таблицы
pandas. Ученик курса начинает с нуля: не знает программирования и Excel.
Между модулем 1 (SQL) и модулем 2 (pandas) ему не на что опереться.

Это часть подпроекта «простой язык» (вторая очередь: вводные 0.2 и 0.3).
Урок 0.3 «Статистика на пальцах» — отдельный цикл тем же способом.

## Объём

- Урок 0.2 «Python с нуля»: пошаговый, как 0.1, девять шагов, ≈ 55 минут.
- Движок шагов научится запускать Python и сверять напечатанное.

## Место в курсе и порядок прохождения

В `lessons.js` урок стоит в модуле 0 вторым:

```js
{ id: "m0l2", title: "Python с нуля", kind: "python", ready: true, steps: true,
  before: "m2l1",
  desc: "print, списки и таблица pandas на знакомых заказах — перед модулем 2",
  say: "…", sayTask: "…" }
```

Номер считается по месту в модуле — «0.2»; номера остальных уроков не
меняются.

`Course` строит порядок прохождения (`Course.ready`) так: урок с полем
`before` переносится прямо перед указанным уроком. Карта курса
(`Course.flat`, оглавление, номера) не меняется. Отсюда:

- после 0.1 кнопка «дальше» по-прежнему ведёт в 1.1, и итоговая фраза
  0.1 «Следующий урок — соединение таблиц» остаётся верной;
- после 1.8 «дальше» ведёт в 0.2, после 0.2 — в 2.1;
- `Stats.resume()` сам предложит 0.2, когда модуль 1 пройден.

Модуль 0: `sub` и `weeks` описывают оба урока; оглавление показывает
«перед модулем 2» через `desc`. В начале теории 2.1 — строка «Python
впервые? Начните с урока 0.2 „Python с нуля“: около часа, и код ниже
станет читаться».

## Движок шагов: второй язык

`Steps.render` уже ведёт ленту шагов для SQL (0.1 и практикумы). Для
урока с `kind: "python"` меняется только запуск и проверка:

- **Запуск.** `Engine.python(["pandas"])`, в глобальные переменные —
  `window.SH.pyData`, перед кодом шага — `window.SH.pyPrelude`: `users`,
  `orders`, `events` уже загружены, как в модуле 2. Печать собирается из
  stdout; stderr (предупреждения библиотек) в сравнение не идёт.
- **Проверка.** `Check.python(stdout, step.expected.stdout)` — та же
  построчная сверка, что в Python-уроках. Шаг хранит `expected:
  { stdout: "…" }`.
- **Вид.** Редактор в режиме Python, подпись «шаг N.py», вывод — текст
  в `<pre>`; ошибка — последние строки трассировки красным и статус
  «Код упал с ошибкой».
- **Первый запуск.** Python качается 15–40 секунд, поэтому загрузка
  начинается при открытии урока. Над шагами строка «Готовлю Python в
  браузере — 15–40 секунд, можно читать первый шаг»; когда готово —
  исчезает. «Запустить» до готовности ждёт той же загрузки.
- Таблицы «было → стало» (`ba`) работают без изменений.

Страница урока: `renderStepsLesson` берёт подпись вида урока («SQL с
нуля» / «Python с нуля») и итоговую фразу из содержимого урока
(`C.finish`), а не из кода.

## Шаги

| # | Шаг | Что напечатать |
|---|---|---|
| 1 | `print` и арифметика | всего заказов: 189 + 13 + 13 |
| 2 | Переменные и текст в кавычках | «Оплачено: 189 из 215» |
| 3 | Функции и аргументы: `round(x, 1)`, аргумент по имени `ndigits=1` | доля оплаченных, 87.9 |
| 4 | Списки: `[…]`, `len`, `sum`, `max` | число, сумма и максимум сумм одного клиента |
| 5 | Таблица pandas: `len(orders)`, столбец `orders["revenue"]`, `.sum()` | 215 и общая выручка |
| 6 | Отбор строк = `WHERE`: `orders[orders["status"] == "paid"]` | 189 и выручка оплаченных |
| 7 | Сортировка и первые N = `ORDER BY … LIMIT`: `sort_values(…, ascending=False).head(3)`, столбцы списком | три самых дорогих заказа |
| 8 | Группировка = `GROUP BY`: `groupby("status")["revenue"].sum()` | выручка по статусам |
| 9 | Сами: пять самых дорогих оплаченных заказов | фильтр + сортировка + первые 5 |

В шагах 5–8 — параллель с SQL и таблицы «было → стало»; в шаге 6
«стало» показывает столбец True/False: в квадратных скобках остаются
строки с True. Шаг 9 без фильтра выдаст первым возврат на 14 473,88 ₽.

Задания строятся на выводе, который не зависит от версии pandas: числа,
короткие таблицы, `Series` с числами. Не печатаем `dtypes` и `Series`
текстовых значений (в pandas 3 у них тип `str`, в браузерном 2.2 —
`object`).
