# Тетрадь аналитика

Интерактивный курс подготовки к позиции Junior Data Analyst / Product Analyst.
SQL и Python выполняются прямо в браузере.

---

## Что отдавать ученику

**Один файл: `Тетрадь аналитика.html`.**

Внутри уже всё — уроки, учебная база данных, оформление, логика проверки.
Человек скачивает файл, делает двойной клик и занимается. Ни папок,
ни установок, ни дополнительных файлов.

Нужен только интернет: редактор кода, Python и SQLite подтягиваются
при первом запуске. Первый запуск Python занимает 15–40 секунд,
дальше мгновенно.

## Прогресс

Пройденные уроки, весь написанный код и заметки сохраняются автоматически
в браузере ученика и подхватываются при следующем открытии. Никаких
действий и никаких лишних файлов для этого не нужно.

Проверено на реальных браузерах при открытии файла двойным кликом:

| Браузер | Результат |
|---|---|
| Safari 26 | прогресс сохраняется и возвращается после перезагрузки |
| Chrome 151 | прогресс сохраняется и возвращается после перезагрузки |

Прогресс привязан к конкретному браузеру на конкретном компьютере.
Если ученик пересядет за другой компьютер, прогресс можно перенести:
в окне «Прогресс» (кнопка со счётчиком уроков в шапке) есть неприметная
строчка «выгрузить прогресс» и «загрузить его там».

Единственный случай, когда браузер не даст сохранять, — **приватное окно**
или очень строгие настройки приватности. Курс это определяет сам,
показывает предупреждение вверху и предлагает выгрузить прогресс в файл,
чтобы результат не пропал. В обычном окне такого не бывает.

## Для себя: как править курс

Собранный html руками не правится — он пересобирается из исходников.

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | оформление, светлая и тёмная темы |
| `lessons.js` | карта курса: модули, названия уроков, флаг `ready` |
| `content.js` | содержание уроков: теория, задача, эталон, подсказки, решение |
| `data.js` | учебная база «Дельта Маркет»: SQL-дамп и CSV |
| `app.js` | логика: редактор, запуск кода, проверка, прогресс |
| `build.py` | сборщик единого файла |

Порядок работы:

1. Правите исходники.
2. Проверяете — открыть `index.html` двойным кликом.
3. Пересобираете файл для отправки:

```bash
python3 build.py
```

### Как открыть новый урок

У каждого урока в `lessons.js` есть флаг `ready`. Урок становится доступным,
когда `ready: true` **и** в `content.js` появился объект с его `id`.
После правки — `python3 build.py`.

## Учебные данные

База «Дельта Маркет» — интернет-магазин, данные за январь–сентябрь 2024,
сгенерированы детерминированно (seed = 42).

```
users    220 строк   user_id, signup_date, channel, city, platform
orders   215 строк   order_id, user_id, order_date, revenue, status
events  1488 строк   event_id, user_id, event_date, event_name
```

Одни и те же данные используются в SQL- и Python-уроках, поэтому ответы
сверяются между модулями: если числа разошлись — где-то ошибка.

SQL-движок — SQLite (sql.js). Оконные функции и CTE поддерживаются,
функции для дат отличаются от PostgreSQL и ClickHouse — это разбирается
в самих уроках.
