# Тетрадь аналитика

Интерактивный курс подготовки к позиции Junior Data Analyst / Product Analyst.
SQL и Python выполняются прямо в браузере.

**Курс открыт здесь: https://nekozlovskiy.github.io/analyst-notebook/**

---

## Что отдавать ученику

**Ссылку.** Это основной способ: адрес не меняется, поэтому каждая новая
версия курса подхватывает прогресс ученика сама — ничего переносить не нужно.

**Или один файл: `Тетрадь аналитика.html`.** Внутри уже всё — уроки, учебная
база данных, оформление, логика проверки. Человек скачивает файл, делает
двойной клик и занимается. Годится, когда ссылку дать нельзя.

Нужен только интернет: редактор кода, Python и SQLite подтягиваются
при первом запуске. Первый запуск Python занимает 15–40 секунд,
дальше мгновенно.

## Без интернета

Сайт кладёт себя в браузер и дальше открывается с диска: страница,
оформление и уже прочитанные уроки работают без связи. Чтобы курс
открывался целиком — все сорок уроков и учебная база, — есть кнопка
**«Сохранить курс на устройство»** в окне «Прогресс»: около трёх
мегабайт, и дальше можно заниматься в метро и в самолёте.

Python остаётся исключением: его движок весит десятки мегабайт, при
первом запуске он всё равно просит связь. SQL без интернета работает.

С телефона курс можно поставить на домашний экран как приложение —
за это отвечает `manifest.webmanifest`.

**Выпуская новую версию, поменяйте `VERSION` в `sw.js`.** Иначе у тех,
кто уже заходил, останется вчерашняя страница из кеша. После смены
версии человек увидит подсказку «курс обновился» и получит новое при
следующей перезагрузке.

## Прогресс

Пройденные уроки, весь написанный код и заметки сохраняются автоматически
в браузере ученика и подхватываются при следующем открытии. Никаких
действий и никаких лишних файлов для этого не нужно.

Проверено на реальных браузерах при открытии файла двойным кликом:

| Браузер | Результат |
|---|---|
| Safari 26 | прогресс сохраняется и возвращается после перезагрузки |
| Chrome 151 | прогресс сохраняется и возвращается после перезагрузки |

Прогресс привязан к браузеру и к адресу, откуда открыт курс. Пока курс
открывают по ссылке, любая новая версия продолжает занятия сама — адрес
тот же. То же верно и для файла: новая сборка, открытая в том же браузере,
подхватывает прогресс прежней.

Перенести занятия в другой браузер или на другой компьютер можно файлом:
в окне «Прогресс» (кнопка со счётчиком уроков в шапке) — «выгрузите
прогресс», а на новом месте просто перетащите этот файл на страницу.
Перенос ничего не стирает: пройденное складывается, а код и заметки,
набранные на новом месте, остаются нетронутыми.

Вернувшегося ученика на главной встречает карточка «продолжить» — урок,
на котором он остановился, или следующий непройденный — и его цифры:
сколько уроков пройдено, сколько времени отдано курсу и сколько дней
подряд он занимается.

Вопросы из самопроверки возвращаются на главную через 1, 3, 7 и 21 день.
Верный ответ отодвигает вопрос на ступень дальше, ошибка возвращает его
на завтра, верный ответ на последней ступени — вопрос выучен.

Единственный случай, когда браузер не даст сохранять, — **приватное окно**
или очень строгие настройки приватности. Курс это определяет сам,
показывает предупреждение вверху и предлагает выгрузить прогресс в файл,
чтобы результат не пропал. В обычном окне такого не бывает.

## Для себя: как править курс

Собранный html руками не правится — он пересобирается из исходников.

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | оформление, светлая и тёмная темы |
| `lessons.js` | карта курса: модули, уроки, флаг `ready`, реплики наставника |
| `content-core.js` | общие куски уроков: описание базы, прологи для Python |
| `content-m1.js` … `content-m6.js` | содержание уроков по модулям: теория, задача, эталон, подсказки, решение |
| `data.js` | учебная база «Дельта Маркет»: SQL-дамп и CSV |
| `app.js` | логика: редактор, запуск кода, проверка, прогресс, повторение, поиск и клавиши |
| `sw.js` | работа без интернета: что кладётся в кеш браузера и когда обновляется |
| `manifest.webmanifest` | описание приложения для установки на домашний экран |
| `favicon.svg`, `apple-touch-icon.png`, `og.png` | иконки и картинка-превью ссылки |
| `инструменты/og.html`, `инструменты/icon.html` | исходники картинок: открыть на локальном сервере и снять экран |
| `инструменты/devserver.py` | локальный сервер без кэша для проверки правок |
| `build.py` | сборщик единого файла |

Порядок работы:

1. Правите исходники.
2. Проверяете на локальном сервере без кэша — правка видна сразу после
   перезагрузки страницы: `python3 инструменты/devserver.py 8779`,
   затем открыть http://localhost:8779. На localhost `sw.js` работает
   «сначала сеть», поэтому кеш правок не прячет.
3. Пересобираете файл для отправки:

```bash
python3 build.py
```

На сайте модули уроков и учебная база грузятся по требованию: главная
не тянет ни то ни другое, урок подгружает только свой модуль, база
приходит перед первым запуском кода. В собранный файл `build.py` кладёт
всё внутрь заранее — у файла, открытого с диска, рядом ничего нет.

### Как открыть новый урок

У каждого урока в `lessons.js` есть флаг `ready`. Урок становится доступным,
когда `ready: true` **и** в `content-mN.js` своего модуля появился объект
с его `id`.
После правки — `python3 build.py`.

## Учебные данные

База «Дельта Маркет» — интернет-магазин, данные за январь–сентябрь 2024,
сгенерированы детерминированно (seed = 42).

```
users    220 строк   user_id, signup_date, channel, city, platform
orders   215 строк   order_id, user_id, order_date, revenue, status
events  1488 строк   event_id, user_id, event_date, event_name
```

Одни и те же данные используются в SQL- и Python-уроках, поэтому ответы
сверяются между модулями: если числа разошлись — где-то ошибка.

SQL-движок — SQLite (sql.js). Оконные функции и CTE поддерживаются,
функции для дат отличаются от PostgreSQL и ClickHouse — это разбирается
в самих уроках.
