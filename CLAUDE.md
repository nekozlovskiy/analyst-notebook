# Тетрадь аналитика — как здесь работать

Курс подготовки к Junior Data Analyst: статический сайт на чистом JS без
сборщика. Уроки — `content-m0.js` … `content-m6.js`, карта курса — `lessons.js`,
движок — `app.js`, общие куски уроков — `content-core.js` (`window.SH`),
учебная база — `data.js`. `Тетрадь аналитика.html` собирает `build.py` —
руками этот файл не правят (хук не даст).

Прежде чем менять уроки, прочитать `README.md` (устройство, правила
оформления, форматы шагов и практикумов) и `ПРОГРЕСС.md` (проверенные
числа учебной базы и рецепты проверки).

## Правила, которые легко нарушить

- `id` уроков не меняются; в массивы `steps`, `practicum.steps`, `cards`
  новое дописывается только в конец — позиция и `id` хранят прогресс ученика.
- Каждое число в тексте урока проверено запуском на учебной базе.
- Python-шаги проверяются по напечатанному построчно: в браузере pandas 2.2,
  локально может стоять 3.x. Текстовые Series в печать не выводить — у них
  разная подпись `dtype` в pandas 2 и 3.
- Тон: без восклицаний, каждое утверждение с числом и знаменателем.
- Новая частая ошибка ученика в Python — новое правило в `Check.pyErr` (`app.js`).

## Проверки

    bash инструменты/ci.sh                      # всё, что проверяет GitHub
    node инструменты/checksteps.js <id урока>  # шаги урока или практикума
    python3 инструменты/devserver.py 8781       # сайт без кэша (8779 занят)

Шаг «Всё пересобрано» в `ci.sh` зелёный только после коммита — это норма.
Чистый прогресс ученика в браузере: `localhost:8781` и `127.0.0.1:8781` —
разные origin.

## Как выпускается изменение

Одна ветка — один PR в `main`. Два коммита: содержание, потом «выпуск
ГГГГ-ММ-ДДx» — новая буква в `VERSION` в `sw.js` и пересобранный
`Тетрадь аналитика.html`. PR открывать только в `main`: обязательная
проверка GitHub запускается только для PR в `main`. Сливает PR владелец
курса сам; после открытия PR дать ему команды:

    gh pr checks N --watch -R nekozlovskiy/analyst-notebook
    gh pr merge N --merge -R nekozlovskiy/analyst-notebook

Коммит и PR — только с его согласия.

## Помощники в `.claude/`

- скилл `new-practicum` — практикум к уроку от выбора данных до проверки в браузере;
- скилл `release` (вызывает только человек: `/release`) — выпуск и PR;
- агент `student-walkthrough` — проход урока глазами новичка;
- агент `lesson-reviewer` — проверка дифа по правилам курса перед PR;
- хуки в `.claude/settings.json`: `node --check` и поиск случайных
  иероглифов после правки JS, запрет ручной правки собранного HTML.
